# Emberius - The Blaze Guardian

This is my high school graduation project (matura zaključni izdelek). I made a basic 2D platformer in Unity.

How to install: Just clone the "Emberius - The Blaze Guardian" folder and run 2D IGRA.exe.

If you are interested in documentation look "Matura Zaključni izdelek" (Its written in slovenian).
